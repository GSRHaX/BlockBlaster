# BlockBlaster 🧩
A Block Blast solver that integrates seamlessly with IOS, utilizing shortcuts. Triple tap the back of your iphone, and solutions appear as notifications! 👾🎯


## Local Server Setup

### 1. Install Cloudflared
BlockBlaster uses Cloudflare Tunnel to connect your iPhone to the server running on your computer keeping your data private.
You do **not** need a Cloudflare account for the temporary Quick Tunnel used in this guide.

<b>Windows:</b> Open **PowerShell** and run: `winget install --id Cloudflare.cloudflared`

<b>MacOS:</b> Open **Terminal** and run: `brew install cloudflared`

### 2. Install and Start BlockBlaster
```bash
git clone https://github.com/GSRHaX/BlockBlaster.git
cd BlockBlaster
npm install
npm start
```
### 3. Start tunnel:
Open another terminal ( keep the previous one open ) and run:
```bash
cd BlockBlaster
npm run tunnel
```
> This will return something like: `https://example-random-words.trycloudflare.com/`. Please keep this URL in mind 📝

> Do not close these two terminals. They must remain open so that the BlockBlaster shortcut can communicate with your computer & solve puzzles! ⚠️‼️

## BlockBlaster Shortcut Setup

Quick Download Link: [BlockBlaster Shortcut](https://github.com/GSRHaX/BlockBlaster/raw/refs/heads/main/BlockBlaster.shortcut)

After Download, Please do the following:

1. Open the Shortcut to edit it, and replace `ENTER SERVER URL HERE` with `https://example-random-words.trycloudflare.com/solve` (the url generated by cloudlfare + `/solve` to the end of it)

2. Allow triple tap activation in settings (accessibility) and assign BlockBlaster to it.

3. Open BlockBlast and triple tap the back of your phone while on the puzzle screen. Click Allow for server permissions, and await result notification. 🥳🙌


## Troubleshooting

- If you receive errors / incorrect results, open BlockBlast settings and pick the default styling. 
- Ensure the board and all three pieces are fully visible.
- If Triple Tap is unreliable, try tapping more firmly.
- The shortcut requires an internet connection.
