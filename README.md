# BlockBlaster 🧩
A Block Blast solver that integrates seamlessly with IOS, utilizing shortcuts. Triple tap the back of your phone, and solutions appear as notifications! 👾🎯

# Quick Install

[Download BlockBlaster Shortcut](https://github.com/GSRHaX/BlockBlaster/raw/refs/heads/main/BlockBlaster.shortcut)

### 2. Allow Required Permissions

Run BlockBlaster once from the Shortcuts app.

iOS may ask for permission to:

- Take screenshots
- Access photos
- Connect to the BlockBlaster server
- Display notifications

Allow these permissions for the shortcut to work properly.

### 3. Assign It to Back Tap

1. Open **Settings**.
2. Go to **Accessibility → Touch → Back Tap**.
3. Tap **Triple Tap**.
4. Scroll down to the **Shortcuts** section.
5. Select **BlockBlaster**.

### 4. Use BlockBlaster

1. Open Block Blast.
2. Make sure the entire board and all three available pieces are visible.
3. Triple-tap the back of your iPhone.
4. Wait for the solution notification.
5. Follow the displayed moves in order.

## Troubleshooting

- Make sure Block Blast is open before activating the shortcut.
- Ensure the board and all three pieces are fully visible.
- Run the shortcut manually once to approve all permissions.
- If Triple Tap is unreliable, try tapping more firmly or assign it to Double Tap instead.
- The shortcut requires an internet connection.

## Compatibility

BlockBlaster is designed for iPhone and requires Apple's Shortcuts app.
